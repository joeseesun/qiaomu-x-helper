别让好内容，只剩一个收藏按钮

刷到好帖再也找不到；回复区被重复内容打断；写文章时在编辑器、搜索和图库之间来回切换。X Helper 把这些常用步骤放到顺手的位置。

核心功能

以下界面截图均来自实际生产界面，文章、账号与服务响应使用明确标注的示例数据。

从想法，到文章

正文始终由你掌控。所见即所得与 Markdown 可切换，大纲跟着文章走；代码、表格、公式和 Mermaid 可以一起写。文章自动保存在本机，支持回收站、Markdown 和含图片 ZIP 导入导出。

  • AI 理解当前文章、选区和引用资料，建议以修改卡片呈现，点接受才改正文
  • 主按钮就是「发布到 X」：准备文章与图片、写入 X 文章编辑器草稿，最后检查与发布留给你
  • 微信、知乎、微博、B 站、小红书等常见媒体源已内置，其他来源自动识别并申请权限

查资料，找图，继续写

  • 联网搜索：在对话里搜索与读取公开网页，查看工具进度和可点击来源，也能随时关闭
  • 图片搜索：连接 Unsplash 或兼容代理，搜索、查看来源、下载并插入图片
  • 独立图库：上传图片、访问主动选定的本地文件夹，管理生成结果
  • 后台配图：关闭侧栏后任务继续，重开可找回进度；中断的任务不会自动重新计费

联网、素材和图片生成使用你配置的第三方服务，可能产生费用；图片许可和用途仍需你核对。

模型一次配好，写作时随手切换

先连接服务，再选模型；支持获取模型列表、搜索、手动添加、编辑、删除、启用和默认模型。写作时可直接切换模型与支持的思考档位。

  • 配图单独选择服务与多个模型；联网搜索和图库来源也有自己的设置
  • 服务端点改变时清除原密钥，防止把旧服务凭据发往新地址
  • 配置备份默认不包含 API Key，登录会话始终不导出；恢复前预览并合并，本机已有配置优先

读过的好内容，留得住

打开 X 书签页即保存已加载的书签，支持暂停。备注、标签、原帖链接和正文一起导出 Markdown，适合带到自己的笔记库。书签按登录账号隔离，移除本机副本不会取消 X 收藏。

  • 高级搜索把关键词、作者、日期和互动条件组成可复用查询，直接在 X 打开
  • 待回复保留原文与本机草稿；常用 @ 支持昵称、账号、备注、拼音和首字母搜索
  • 它们不会替你发送回复

整理回复，但不替你做判断

按自己的规则折叠回复：本地词汇规则支持昵称、简介、正文范围与保留名单；可选的 AI 回复判断使用独立的 Jev 决策服务，未知或无效结果保留原文。

  • 回复判断是可能出错的参考，不能证明一个人是 AI 或机器人
  • 不自动拉黑账号，不扫描全部历史，不自动无限滚动
  • 可选社区订阅与贡献默认关闭

常用 @、发帖排期与 X 侧栏

  • 在 X 编辑器点 @ 或输入 @@，按昵称、拼音、首字母搜索联系人；Shift 一次插入多人
  • 发帖页写正文、拖入图片 / GIF / 视频，存草稿或排进「下一个空档」；填入 X 后由 X 自带定时面板发出
  • X 侧栏逐项开关与排序，可添加自己的站内路径、https 网站或插件页面入口

到点提醒与排期内容只存在扩展本机的 IndexedDB，不上传、不进 Chrome 同步。

三步开始

不需要先装 PKG，也不需要先填 API Key。AI 与外部图库是按需连接的可选功能。

下载安装包

打开 v0.5.2 Release，下载 qiaomu-x-helper-0.5.2-chrome.zip 并解压。

加载扩展

在 Chrome 地址栏输入 chrome://extensions，开启「开发者模式」，点「加载已解压的扩展程序」，选择包含 manifest.json 的解压目录。

先做一件有用的事

打开 X 书签页保存已加载内容，或点扩展里的「写作」，开始写第一篇文章。

升级时保留原目录、替换文件后重新加载；先导出重要文章与配置。Chrome 商店公开版为 0.2.0，0.5.2 审核通过后会自动发布到商店页面。

数据与判断的边界

文章、书签和配置默认留在本浏览器，不使用 Chrome Sync。你发起 AI 操作时，所需的正文、选区、指令或图片会发往所选服务；搜索词与网页地址会发给搜索服务。第三方的收费和留存政策由各服务决定。

常见问题

不配置 API Key 能用吗？
能。文章编辑、书签、搜索条件、待回复、常用 @、本地词汇规则都不需要 API Key。AI 写作、联网搜索、云端配图和 AI 回复判断是按需连接的可选功能，使用你自己配置的第三方服务，费用与留存政策由各服务决定。
GitHub Preview 和 Chrome 商店版有什么区别？
截至 2026-10-21，Chrome 商店公开版为 0.2.0；0.5.2 已送审，审核通过后自动发布到同一商店条目。GitHub Release 的 Preview 包包含最新的写作工作台、图库、发帖排期等功能，安装方式为「加载已解压的扩展程序」。
我的数据存在哪里？
文章、书签、配置、发帖排期和附件默认保存在本浏览器的 IndexedDB，不使用 Chrome Sync。配置备份默认不包含 API Key，账号登录会话始终不导出。只有你主动发起 AI / 搜索操作时，相关内容才会发往你配置的服务。
它会替我发帖或回复吗？
不会。发布到 X 只是把文章与配图写入 X 原生草稿；排期帖子由 X 自带的定时面板发出；待回复只是填入对应回复框。所有最终确认都留给你。
AI 回复判断准确吗？会不会误伤？
回复判断是有可能出错的参考，不能证明一个人是 AI 或机器人。未知或无效结果保留原文，不自动拉黑账号；本地先验只在多项线索同时成立且模型分数已偏向 AI 时才上调，折叠也随时可以展开和纠正。
「发布到 X」需要什么条件？
需要已登录 X，且账号本身拥有 X Articles（长文）权限。媒体没准备好时扩展会先停在本地，不会打开 X 或丢掉图片继续写入。
